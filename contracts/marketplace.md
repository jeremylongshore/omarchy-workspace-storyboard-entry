# Workspace Storyboard marketplace contract

- Both manifest descriptions must use all 500 characters and state the live Hyprland map, keyboard/click actions, bounded private history, and no-network boundary.
- The authored SVG banner must identify Workspace Storyboard, Hyprland state, and bounded local re-entry history.
- The preview must be an uncropped 1280x720 frame from the isolated real Omarchy shell with a clean plugin log and exact source/package hashes.
- The rig must run the shipped scanner against four deterministic Hyprland workspaces, create multiple genuine history records, perform a fixed-argv dispatch, and prove the active workspace changed before capture.
- The opened panel must visibly distinguish the active and selected workspace, show meaningful titles/window counts, expose the recent trail and clear action, and keep its keyboard legend readable.
- Human marketplace-scale inspection must be bound to the preview SHA-256 before submission.
